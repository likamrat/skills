# Draft skills

This directory holds experiments that are not installable or published.

Use this shape:

```text
drafts/
└── <category>/
    └── <skill-name>/
        └── SKILL.draft.md
```

Do not name a draft manifest `SKILL.md`; the official CLI may discover it. Promote a draft by completing its evals and checks, moving it under `skills/<category>/`, and renaming the manifest to `SKILL.md`.
